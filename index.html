What happens when a user messages an agent I built

RecallPast facts are pulled from vector memory in Qdrant.
RetrieveKnowledge base chunks are matched by semantic search.
ActThe agent calls tools: Salesforce, Odoo, flight APIs.
AnswerA sub-agent drafts the reply with the chosen LLM.

Projects

Three production systems from my work at Cogveel Technologies, plus smaller ML projects.

Neuragent

Lets a company build its own AI assistant that uses its documents and tools

  • Architected a multi-agent backend on LangChain Deep Agents with sub-agent orchestration, so businesses can create, configure and deploy agents with their own tools and knowledge bases.
  • Supports OpenAI, Gemini, Anthropic, Groq and DeepSeek behind one interface.
  • Built an agentic memory that extracts facts from conversations with an LLM and stores them as embeddings in Qdrant for recall in later sessions.
  • Designed a RAG pipeline over PDF, DOCX, XLSX, HTML and image files with configurable chunking.
  • Connected agents to Amadeus (OpenAPI), Salesforce (OAuth CRUD) and Odoo (Model Context Protocol), so they discover and call real business endpoints at runtime.

FINN.AI

Coaches a salesperson with the right words during a live call

  • Built a live meeting copilot: Silero VAD and Deepgram Nova-2 transcribe calls with speaker diarization, with latency under 300 ms.
  • GPT-4o mini detects topics, objections and sentiment, then sends coaching nudges to the rep.
  • RAG battle cards use all-MiniLM-L6-v2 and pgvector, with a Tavily web-search fallback, streamed over WebSockets.
  • Pre-call pipeline enriches prospects through the Apollo API (tech stack, revenue, buyer personas) and writes a sales brief.
  • A custom Chrome extension shows live coaching cards and grounds the sales chatbot during the call.

  • Added background axle processing, exit event buffering and hourly jobs that reconcile completed trips.
